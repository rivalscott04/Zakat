# Zakat OS — PRD

Kumpulan Product Requirements Document (PRD) per modul untuk Zakat OS.

## Struktur

Setiap modul memiliki dokumen PRD terpisah agar dapat dikembangkan, direview, dan diberikan kepada AI coding agent secara independen.

## Prinsip

- Open source
- Auditability by design
- Sharia rule driven
- Financial integrity
- Public transparency
- Privacy by design
- Modular architecture
- API first
- React + TypeScript frontend
- Laravel backend
- PostgreSQL database

## Status

Dokumen masih berupa template kosong dan akan diisi secara bertahap.
